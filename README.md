# Netloop

Draw a loop. Drop the bad packets.

Android game base, Kotlin + Jetpack Compose. This is the starting skeleton, not the finished game.

Code has no comments on purpose. Every file is documented in the Obsidian vault:
`Documents/Obsidian Vault/Netloop/` → start at **Netloop — Hub**, and **Run the Game** for setup.

- `app/` the Android app
- `sprites/svg/` every sprite frame as SVG, `sprites/preview.html` plays them all
- `tools/sprites/generate_sprites.py` makes the SVGs, the Android vector drawables and `SpriteSheet.kt`
